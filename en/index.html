Plug, Play & Install

Copy HLine-TV.apk onto a stick and open it from the TV's file manager. On TCL / FFALCON, copy HLine-TV-Guard.apk instead — the TV rejects the other one with an install error.

guard

Seamless Fallback for Locked Systems

Some firmware (most often TCL, FFALCON and OPPO) refuses to install an app that declares itself as a home screen. HLine-TV-Guard.apk is the same app without that declaration — it takes over the Home key through an accessibility service, and looks and works identically. Install it from a stick on these sets.

FAQ

More about HLine TV

Does it affect the warranty? How do I go back?

It doesn't root, flash or remove system apps — it only becomes the default home screen. To go back, pick the original home in the TV's settings, or uninstall HLine TV.

Which TVs and boxes are supported?

Android TV 5.0 and later — televisions, boxes and projectors. Xiaomi, Redmi, TCL, FFALCON, Skyworth, Sony, Hisense, OPPO and others have been tried. Samsung (Tizen) and LG (webOS) are not Android and cannot run it.

I get an install error and nothing installs.

Usually the wrong file. HLine-TV.apk has to declare the home category to serve as a home screen, and firmware from TCL, FFALCON and OPPO refuses to install anything that does — on screen it is a plain install error, over adb it is INSTALL_FAILED_VERIFICATION_FAILURE. Use HLine-TV-Guard.apk: the same app without that declaration, taking over the Home key through an accessibility service, and it looks and works identically. TCL also refuses adb installs across the board, so install on the TV itself — a stick, or the TV's own file manager.

Installed, but Home still opens the old screen.

Xiaomi, TCL and Skyworth lock the home role to their own launcher, so a third-party app cannot claim it; HLine TV takes over the Home key through a home guard instead. Three steps, in order: ① allow HLine TV to use accessibility in the TV's settings (some sets also need notification access); ② open HLine TV once more; ③ restart the TV. If it still will not stay, that firmware starts its own launcher from a hard-coded component at power-on — some Skyworth sets do — and we would need to add support for that model. The app itself still works.

Does it collect data or show ads?

The launcher records nothing about what you watch, and has no advertising slot anywhere. Only the features that need the network — weather, wallpapers, updates — use it.

How do updates work?

When the control centre offers a new version, tap "Download and install". It installs over the old one, and your settings and layout stay.

Can I use my own photos and videos?

Yes — from the phone page. Photos become wallpapers, videos become the screensaver, and both stay on the TV.

Do updates keep my layout?

They do. Apps, order, folders, custom icons, wallpapers and settings all survive.

Is it free and open source?

Free, MIT licensed, source on GitHub. No account, no in-app purchases.
