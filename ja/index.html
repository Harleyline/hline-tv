curl 一行インストール

ADB

直接接続してインストール

# adb に慣れている場合（TCL / FFALCON は adb インストールを拒みます）
adb connect TV_IP:5555
adb install HLine-TV.apk
usb

USB で挿して、開くだけ

HLine-TV.apk を USB メモリにコピーし、テレビのファイルマネージャーで開きます。TCL / FFALCON では代わりに HLine-TV-Guard.apk を使ってください。もう一方はインストールエラーになります。

guard

制限の厳しいファームウェアへの代替手段

一部のファームウェア（主に TCL / FFALCON / OPPO）は、ホーム画面を宣言したアプリのインストールを拒みます。HLine-TV-Guard.apk はその宣言を外した同じアプリで、ユーザー補助機能でホームキーを引き継ぎます。見た目も動作も同じです。これらの機種では USB メモリからインストールしてください。

よくある質問

HLine TV について

保証はどうなりますか？ 元に戻せますか？

Root 化、書き換え、システムアプリの削除は行わず、既定のホーム画面になるだけです。戻すにはテレビの設定で元のホームを選ぶか、HLine TV をアンインストールしてください。

対応するテレビとボックスは？

Android TV 5.0 以降のテレビ・ボックス・プロジェクター。Xiaomi、Redmi、TCL、FFALCON、Skyworth、Sony、Hisense、OPPO などで動作確認済みです。Samsung（Tizen）と LG（webOS）は Android ではないため動作しません。

インストールエラーになり、何も入りません。

たいていはファイル違いです。HLine-TV.apk はホーム画面として動作するためにホームカテゴリを宣言する必要があり、TCL / FFALCON / OPPO のファームウェアはそうしたアプリを拒みます。画面上は単なるインストールエラー、adb では INSTALL_FAILED_VERIFICATION_FAILURE と出ます。HLine-TV-Guard.apk を使ってください。宣言を外した同じアプリで、ユーザー補助機能がホームキーを引き継ぎ、見た目も動作も変わりません。TCL は adb インストール自体を拒むため、USB メモリかテレビのファイルマネージャーからインストールしてください。

インストールしたのに、ホームキーで古い画面が開きます。

Xiaomi、TCL、Skyworth はホームの役割を自社ランチャーに固定しているため、サードパーティ製アプリは取得できません。HLine TV はホームガードでホームキーを引き継ぎます。順番に 3 步：① テレビの設定で HLine TV のユーザー補助を有効にする（機種によっては通知へのアクセスも必要）；② HLine TV をもう一度開く；③ テレビを再起動する。それでも固定されない場合、そのファームウェアは電源投入時に決め打ちのコンポーネントから自社ランチャーを起動しています（一部の Skyworth で確認済み）。その機種への対応追加が必要ですが、アプリ自体は動作します。

データ収集や広告はありますか？

視聴内容は一切記録せず、広告枠もどこにもありません。ネットワークを使うのは天気・壁紙・更新など、必要な機能だけです。

アップデートはどう行われますか？

コントロールセンターに新しいバージョンが表示されたら「ダウンロードしてインストール」を選んでください。上書きインストールされ、設定とレイアウトはそのまま残ります。

自分の写真や動画を使えますか？

はい。スマートフォンの設定画面から追加できます。写真は壁紙、動画はスクリーンセーバーになり、どちらもテレビ本体に保存されます。

アップデートでレイアウトは残りますか？

はい。アプリ、並び順、フォルダ、カスタムアイコン、壁紙、設定はすべて引き継がれます。

無料でオープンソースですか？

無料・MIT ライセンス、ソースは GitHub にあります。アカウント登録も課金もありません。
